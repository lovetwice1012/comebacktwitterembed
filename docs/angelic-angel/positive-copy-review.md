# 利用者向け説明文の整理

2026-10-14 JST。配布版 `0.1.0-preview.4`。

保存ツール、同梱の説明書、Webの登録・監視・枠変更画面を、できること・操作・次の手順の順に書き直した。
ボタン名と説明文を揃え、同じ注意の繰り返しを減らした。

| 以前の表現 | 改稿例 |
|---|---|
| ファイルの登録だけでは通知は届きません | 通知を届けるには、サーバー接続と、監視するアカウント・通知先の設定が必要です |
| 通知の登録・引継ぎはまだ完了しません | このPCでファイルを作成し、Webの登録画面からご自身でアップロードします |
| 処理品質は現在の契約プランで決まります | 確認間隔と送信上限には、現在の契約プランを適用します |
| 技術的には取得可能な範囲に入ります | サーバーに届く以上、これらのデータや情報は運営側でも取得できる状態になります |

他サイトの暗号化データ・識別情報がサーバーへ届く可能性、現在の破棄方針、利用には別途許可が必要なこと、
破棄した通知を後からFirefoxで受け取れない可能性は、保存前の確認とWebの説明で案内する。
ファイルはX用の情報だけを保存し、利用者がWebからアップロードする流れを維持する。
現在の受付状態や接続状態に合う表現とし、実X通知での確認段階も明記した。
