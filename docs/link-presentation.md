# メインBotの画像ギャラリー・過去の共有表示

通常のURL投稿を対象に、次の2機能を追加します。

## 画像ギャラリー

Discordの `/guisetting` から Pixiv または Instagram を選び、
「画像ギャラリーの表示方式」で「通常表示」か「ページ切替式ギャラリー」を選択します。
未設定時は通常表示です。変更は以後のURL展開に適用されます。

ダッシュボードのサーバー設定からも、Pixiv／Instagramの「画像ギャラリーの表示方式」で
同じ設定を変更できます。変更差分は選択肢名で表示し、プレビューにもページ操作の表示例を出します。

- ギャラリーでは公開カードに最初の1ページを表示します。
- 「前へ」「次へ」「自分用に開く」を押すと、押した本人にだけ見える画面を開きます。
  その後は本人の画面だけを更新し、他の利用者のページ位置は変えません。
- 既存の枚数上限・URLの画像番号指定を維持します。対象が1件なら通常表示を使います。
- Instagramの画像・動画混在時は既存の添付順を維持して1件ずつ表示します。
- メディア非表示、リンクのみ、サムネイルのみの設定を上書きしません。
  spoiler添付は各ページでもspoiler添付のままです。
- ギャラリーのスナップショットはDBに30日間保存します。Bot再起動後も操作できます。
  配信元のメディアURLが先に期限切れになる場合は表示できないことがあります。
- 設定変更・プロバイダー停止・操作制限を再確認します。公開カードを削除した場合や
  チャンネル履歴の閲覧権限を失った場合、その個人ビューのページ操作も停止します。
- 保存できなかった場合は画像を省略せず、元の通常表示で送信します。

## 過去の共有表示

同じサーバー・同じチャンネルで以前に展開成功したリンクには、今回も通常どおり
展開したうえで次の補足を付けます。ギャラリー設定とも併用できます。

> このチャンネルで以前にも共有されています · 前の投稿を見る

各サービスの設定にある「過去の共有リンクを表示」でON/OFFを切り替えられます。
初期値はONです。OFFでも今回の通常展開は継続し、その間の履歴参照・記録は行いません。
設定はダッシュボードとDiscordの既存設定画面で共通です。

- 元の投稿、削除済みなら確認できるBot応答へのリンクを表示します。
  両方が削除されている場合は補足を付けません。
  過去の投稿の確認にはBotの「メッセージ履歴を読む」権限が必要です。
- 他チャンネル・別サーバーの共有履歴は表示しません。スレッドもそれぞれ別のチャンネルとして扱います。
- 同一判定にはプロバイダーの正規URLを優先し、Twitter/XのURL表記差や追跡用パラメーターを正規化します。
  動画IDなどの意味のあるクエリーパラメーターは保持します。
- 同じ元メッセージの再試行、取得失敗、送信未確認、意図的な展開省略は過去の共有に加えません。
- 履歴は導入後に成功した展開から蓄積します。過去のメッセージを一括取得しません。
  保存するのはチャンネル・メッセージID・URLのハッシュ・時刻で、本文は保存しません。
  チャンネルとリンクごとの直近1件を保持し、180日を過ぎた履歴は対象外として順次削除します。
- 履歴DBや過去メッセージの取得に失敗しても、今回の通常展開は継続します。

## 導入・検証

Discord送信処理からの保存・メッセージ紐付けを確認します。Discordの送信APIは模擬であり、
実際のDiscord画面の表示・操作は本番導入後の確認が必要です。
