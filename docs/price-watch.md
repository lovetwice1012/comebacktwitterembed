# Amazon / Steam 価格通知

Amazonの商品ページとSteamのアプリ・パッケージ・バンドルを展開したとき、価格を取得できた場合だけ「価格通知」ボタンを表示します。

## 登録方法

ボタンを押すと、次の6通りから選べます。

選択前に内容・権利・通知先を利用者が確認します。機械チェックの通過は適法性・安全性の保証ではありません。通常の管理者承認や審査保留は使いません。

- 価格変動をDM / 既存Webhook URL / 選択チャンネルにBotが作成したWebhookへ通知
- 上限価格または最低割引率の条件達成をDM / 既存Webhook URL / 選択チャンネルにBotが作成したWebhookへ通知

チャンネル方式では、押した人とBotの双方に対象チャンネルの「Webhookの管理」権限が必要です。Botは完了時にだけWebhookを作成します。既存Webhook URLも、操作したサーバーに属するものだけを受け入れます。

価格変動通知は、前回観測価格との差額、前回価格、現在価格を毎回送ります。条件通知は、価格が上限以下または割引率が下限以上へ遷移した時だけ送信し、条件から外れた後に再度到達した場合は再通知します。

## 取得と安全性

- Amazonは展開と同じ公開商品ページから販売価格を取得します。取り消し線価格を取得できたときは割引率も計算します。
- Steamは公開Store APIを優先し、アプリ以外は公開ストアページから価格を取得します。展開時と同じ地域・言語を使います。
- 価格不明、ログイン必須、配送先・バリエーション依存などで信頼できる販売価格を取得できない回は通知せず、後で再試行します。0円は有効な価格です。
- 同一商品・同一地域の取得は共有されます。初回取得は基準価格の保存だけで通知しません。
- 価格イベントは配信アウトボックスへ永続化されます。再試行できる失敗はバックオフし、一部送信済み・送信結果不明は一括再送しません。機械チェックの拒否・故障は、その操作の結果として記録します。

既定の確認間隔はAmazonが60分、Steamが30分です。プロバイダーごとの取得は直列化し、Amazonは5秒、Steamは2秒以上の間隔を置きます。
