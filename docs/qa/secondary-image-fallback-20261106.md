# セカンダリモードの画像表示

自動通知の通常展開は元メッセージのDiscordプレビューを抑制する。
セカンダリモードが画像1枚の投稿を見送ると画像が表示されないため、
対象の画像が元メッセージに表示されていない場合は画像を1枚補う。
既に対象の画像プレビューが表示されている場合は重複して送らない。
引用展開、通知先、画像の表示方法、元メッセージの保持も確認する。

Discordのプレビュー生成は非同期なので、元投稿が抑制されていない
状態で画像補完を送った後、Discordのプレビューが遅れて現れる場合は
一時的に重複する可能性がある。

2026年11月6日、報告された画像1枚のX投稿3件を実際に取得し、画像
補完の出力と画像URLのHTTP応答を確認した。Discordへの実送信や
受信者のクライアント表示はこの取得試験には含まれない。

画像表示方法をリンクのみとする明示設定は引き続き尊重する。
Discordの送信権限がない場合は画像を送れず、元投稿を変更しない。
