## レビューと修正

- 初回の追加欄を既存の動画監視の新着として配信しないよう、sourceと対象別の基準を同じDBトランザクションで保存する。

- 取得中に設定がオンになっても、その欄を実際に取得するまで確認済みにしない。SQLで競合と再試行を確認した。
- RSSが304でも追加欄を確認する。取得・DB保存の失敗でcursorを進めない。
- 公開クロールの停止中も通常のAtom取得を維持する。追加欄の再開時は基準を取り直す。
- シングルは通常の動画展開、アルバムは全曲のプレイリストを使う。RSSに同じシングルがある場合は重複させない。
