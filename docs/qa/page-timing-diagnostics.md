# 画面表示のローカル計測

画面表示の確認時だけ、同じブラウザータブ内で計測を有効にできます。初期状態では計測しません。計測値はメモリー上に最大64件を保持し、タブを閉じると消えます。送信・永続保存はしません。

計測するのは固定の画面名、初期データの読み込み結果（`ready` または `error`）、所要時間だけです。ユーザーID、URLやそのパラメーター、通知本文、通知先、ブラウザー識別子は取得しません。画面切替やタブの非表示で完了しなかった計測、2分を超えた計測は破棄します。

対象は `notifications`（通知一覧の初回取得）、`x_monitors`（X監視一覧・利用枠・受信情報の初回取得）、`delivery_history`（配信一覧の初回取得）、`plans`（プランと契約状態の初回取得）です。開始点はその画面が表示されて初回取得を始める直前、終了点はデータまたはエラーが反映された後の描画フレームです。ブラウザーのページ遷移・サーバー描画の時間や、後から開く履歴の詳細は含みません。10ミリ秒単位に丸めます。

## 有効化と確認

未保存の入力がないことを確認してから、対象タブの開発者ツールで次を実行し、画面を再読み込みします。

```js
sessionStorage.setItem('cbte.pageTiming', '1')
location.reload()
```

対象画面を開いた後、同じタブの開発者ツールで確認します。

```js
window.__cbtePageTimings?.snapshot()
```

確認後に計測値を消し、無効化できます。

```js
window.__cbtePageTimings?.clear()
sessionStorage.removeItem('cbte.pageTiming')
```

これは操作したタブだけの診断結果です。全利用者の平均や95パーセンタイル、サーバー全体の性能を示すものではありません。複数利用者に調査を依頼する場合は、その都度収集する値と用途を伝えて同意を得てください。
