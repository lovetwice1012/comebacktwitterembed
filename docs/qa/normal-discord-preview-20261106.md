# 通常通知のDiscordプレビュー

通常展開の自動通知では、Discord標準プレビューの抑制フラグを
付けずに送信する。通知は従来どおり通常のBot展開へ引き渡し、
セカンダリモードの見送り条件は変更しない。テキストのみ・URLのみの
表示形式に設定された抑制は維持する。

画像1枚とセンシティブな投稿のテストでは、セカンダリモードが
見送った際にBotが画像を別送しないことを確認した。通知の通常経路、
複数通知の集約、価格通知、送信失敗時の扱いも回帰テストした。
報告された画像投稿3件の公開取得では、抑制フラグなしの通常通知と
セカンダリによる見送りを確認した。Discordへの実送信は行っていない。

Discord側が実際にプレビューを生成するかは、投稿の公開状態や
Discord側の取得・表示条件に依存する。Bot展開と標準プレビューが
両方表示される場合もある。
