# X通知データの保存ツール

バージョン: 0.1.0-preview.4（検証用）

専用FirefoxからX通知の情報を取り出し、Webへのアップロード用ファイルをPCに作ります。
作成後は、利用者自身が案内されたWeb画面でファイルを選んでアップロードします。

**ZIPを「すべて展開」し、「ダブルクリックで開始.cmd」をダブルクリックしてください。**
日本語画面のボタンで操作できます。初めて使う方は、同梱の「はじめに読んでください.txt」もご覧ください。

## 使い方

1. ZIPを右クリックして「すべて展開」し、**ダブルクリックで開始.cmd** を開きます。
2. **専用環境を準備する** を押します。普段使いとは別に、このツール専用のFirefox設定を用意します。
3. **Xの設定用Firefoxを開く** を押します。Xにログインし、対象アカウントの投稿通知とブラウザー通知を設定します。
4. 設定用のFirefoxを閉じ、**アップロード用ファイルを作る** を押します。保存先と読み取る内容を確認して保存します。
5. 案内されたWeb画面で、保存したファイルを選んでアップロードします。

Firefoxが見つからないときは、**Firefoxを選ぶ** から `firefox.exe` を選択できます。
Firefox本体をインストールしたWindowsで利用できます。コマンド入力や管理者としての起動は必要ありません。
Windows PowerShell 5.1とPowerShell 7で動作を確認しています。通常の利用では、同梱のスクリプトとFirefoxを使います。

## 読み取る情報とファイルの扱い

出力ファイルには、専用Firefoxの通知先ID、X通知の登録先、通知を読み取るための鍵、
Firefoxのバージョンなどの確認情報を保存します。Cookie、保存パスワード、閲覧履歴は読み取り対象に含めません。

ツールが担当するのは、PC内でのファイル作成までです。
Webへのアップロードは、利用者自身が画面上で行います。
元のFirefox本体と通知データはそのまま残し、作業用コピーから必要な情報を読み取ります。

ファイルにはX通知を読み取るための鍵が入っています。案内されたWeb画面へのアップロードに使い、
PCでは本人だけが開ける場所に保管してください。SNSやチャットに内容を貼り付けると、その相手も通知を読める可能性があります。

ファイル自体は暗号化せず、作成時から本人とWindowsのSYSTEMだけが読めるアクセス権を付けます。
保存先にはアクセス権を保持できるPC内のフォルダーを選び、毎回新しいファイル名で保存してください。

### ほかのサイトの通知も設定されている場合

保存するのは、X用の通知情報と鍵です。他サイトの鍵・通知本文・サイト一覧は出力対象に含めません。
専用Firefoxにほかのサイトの通知も設定されている場合は、保存直前の画面で次の内容を説明し、今回の作成について確認します。

同じFirefoxでは通知の受け取り先が共通です。ファイルをアップロードしてサーバー側で受信を始めると、
**ほかのサイトの暗号化された通知データや、どの通知かを見分けるための情報も届く可能性があります。**
サーバーに届く以上、これらのデータや情報は運営側でも取得できる状態になります。

現在、サーバーではX通知だけを扱い、X以外の通知データは届いた時点で破棄します。
X以外の通知の保存・復号・利用を始める際には、あらためて明確な許可をいただきます。
**サーバーで破棄した通知は、後からFirefoxなどで受け取れない場合があります。**

「はい」でファイルを作成し、「いいえ」で確認画面を閉じます。確認は作成のたびに行います。
他サイトの通知を利用するための許可は、この確認とは別にいただきます。

## 検証状況

この版は、ファイル作成機能を確認するための検証版です。
Firefoxの実際の保存形式にテスト用の通知データを入れ、読み取り、ファイル保存、元データの保持、一時データの片付けを確認しています。
次の確認段階は、実際のX通知を使ったWeb登録から通知受信までの一連の動作です。
使用したFirefoxのバージョンと試験結果は、配布元の検証記録をご覧ください。

## 読み取りと通信の仕組み

- 専用設定の保存先は、既定で `%LOCALAPPDATA%\XNotificationSetup\FirefoxSetupPreview` です。
- 専用環境の所有情報とアクセス権を確認し、専用Firefoxが閉じている間に通知保存情報をコピーします。
- 読み取る元データは、既知の通知DB関連ファイルと、`prefs.js` 内の通知識別値1項目です。
  通知に必要な情報へ対象を絞り、普段使いのプロファイルやCookie・パスワード・履歴のDBを読み取り対象から外しています。
- Firefox本体と通知情報の作業用コピーを、通信を停止した状態で起動します。
  公開されたテキストコードをFirefox内で実行し、読み取り専用で通知情報を確認します。リモート制御用ポートは使用しません。
- 作業用ブラウザーの終了と一時コピーの削除を確認してから、指定された新規ファイルを保存します。
  作業中はFirefoxアプリ本体のコピーを置く空き領域が必要です。
- **Xの設定用Firefoxを開く** を押すと、通常のFirefoxがXやMozillaなどへ通信します。
  Xへのログインと通知設定は利用者がブラウザー上で行います。
- Webへの登録は、ファイルを作成した後の手動アップロードで行います。

## 保存先の条件

本人とSYSTEMだけが読めるアクセス権を設定できることを確認してから、ファイルの内容を書き込みます。
アクセス権を保持できるPC内のフォルダーへ、新しい名前で保存してください。
ネットワーク共有、再解析ポイント、配布フォルダー内、専用環境内、既存のファイルを保存先に選んだ場合は、別の保存先を案内します。

処理が途中で止まった場合は、画面の案内を確認して再実行してください。
作業用ブラウザーの終了や一時データの片付けを含め、必要な処理が完了した段階で、ファイル作成の完了を表示します。

## ソースの見方

スクリプトはメモ帳などで読めます。各処理の目的と対象を、日本語のコメントで説明しています。

| ファイル | 役割 |
|---|---|
| ダブルクリックで開始.cmd | 日本語の操作画面を開く |
| Start-Setup.ps1 | 説明、実行前の確認、保存場所の選択、結果案内 |
| Setup-XNotifications.ps1 | 操作の入口と、配布物・専用環境・Firefoxの停止状態の確認 |
| FirefoxReader.ps1 | Firefox本体の作業用コピーと、通信を停止した読み取り用Firefoxの管理 |
| Export-XNotificationData.ps1 | 通知情報のコピー、識別値の確認、一時データの片付け、アクセス権を設定した新規ファイルの保存 |
| Read-PushSubscription.js | Firefox自身の保存形式で通知設定を調べ、X通知1件の情報と鍵を検証 |
| はじめに読んでください.txt | 初めて使う方向けの操作説明 |
| package-manifest.json | 配布ファイルの不足・変更・追加を確認するための照合情報 |

## 配布物の照合

画面を開く前と処理を始める前に、必要な全ファイルを照合します。
配布元の確認には、信頼できる配布ページと、別途公表されたZIPのSHA256もお使いください。
同梱ファイル同士の照合は、電子署名とは役割が異なります。起動スクリプトと照合情報の両方が書き換えられた場合は、
別途公表されたハッシュ値との比較が、配布元のZIPと同じ内容か確かめる手段になります。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\x-notification-setup-0.1.0-preview.4.zip
```

## コマンドで実行する

開発・保守で直接実行する場合の例です。通常は日本語画面から操作できます。

```powershell
.\Setup-XNotifications.ps1 -Action Status
.\Setup-XNotifications.ps1 -Action Export -OutputPath C:\Users\自分の名前\Desktop\X通知.json -WhatIf
```

`-WhatIf` は、実行する予定の処理を表示します。コピー、Firefoxの起動、出力ファイルの作成は、通常の実行時に行います。
CLIでほかのサイトの通知設定が見つかった場合は、確認内容を表示して終了します。
上記「ほかのサイトの通知も設定されている場合」を読み、今回のファイル作成に同意する場合は、
`Export` の引数へ `-AllowOtherNotifications` を追加して再実行してください。
他サイトの通知を利用するための許可は、この指定とは別にいただきます。

`Transfer` は、利用者自身がWeb画面でアップロードする手順を案内します。
起動時の実行ポリシーは、その起動プロセスだけに適用します。PC全体の設定はそのまま保ちます。
